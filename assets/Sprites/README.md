# 图片资源文件夹

这个文件夹包含游戏中使用的所有图片资源。

## 目录结构

### Background/
存放背景相关的图片资源：
- **主菜单背景**: menu_bg.png
- **游戏背景**: game_bg.png  
- **星空背景**: starfield.png
- **地面/边界**: ground.png, boundary.png

**建议规格**:
- 分辨率: 1920x1080 或更高
- 格式: PNG（支持透明）或 JPG
- 大小: 尽量控制在 2MB 以内

### Roles/
存放角色相关的图片资源：

#### 玩家角色
- **飞船主体**: player_ship.png
- **飞船推进器特效**: player_thrust.png
- **玩家子弹**: player_bullet.png

#### 敌人角色  
- **基础敌人**: enemy_01.png
- **中型敌人**: enemy_02.png
- **Boss敌人**: enemy_boss.png
- **敌人子弹**: enemy_bullet.png

#### 特效图片
- **爆炸序列帧**: explosion_01.png ~ explosion_08.png
- **击中特效**: hit_effect.png
- **道具图标**: powerup_*.png

**建议规格**:
- 分辨率: 64x64 到 256x256
- 格式: PNG（保持透明背景）
- 命名规范: 类型_名称_序号.png

## 图片导入设置

在Cocos Creator中导入图片时的建议设置：

### 背景图片
- **类型**: Sprite
- **包装**: Individual（单独打包）
- **压缩**: 根据平台选择（Web: WebP, 移动端: ETC/PVRTC）

### 角色图片  
- **类型**: Sprite
- **包装**: Auto Atlas（自动图集）
- **压缩**: 高质量压缩
- **过滤**: Linear（线性过滤）

### 序列帧动画
- **类型**: Sprite
- **包装**: 放入同一图集
- **命名**: 确保序列帧名称有序

## 图集配置

建议创建以下图集：
1. **ui_atlas**: UI相关图片
2. **player_atlas**: 玩家相关图片  
3. **enemy_atlas**: 敌人相关图片
4. **effect_atlas**: 特效相关图片

## 优化建议

1. **文件大小**: 单张图片不超过 1024x1024
2. **透明通道**: 只在必要时使用透明通道
3. **图集效率**: 相关图片放在同一图集中
4. **命名规范**: 使用清晰的命名约定
5. **版本控制**: 大型图片文件考虑使用 Git LFS

## 创建占位符

在实际开发中，可以先创建简单的占位符图片：
- 玩家: 蓝色三角形
- 敌人: 红色圆形  
- 子弹: 黄色小圆点
- 背景: 渐变色填充
